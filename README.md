# Vaadanamb Procurement Agent UI

A simple Next.js app for configuring procurement follow-up agents, LLM provider settings, and supplier inputs.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`

## Features

- Configure agent details, PO context, supplier preferences, follow-up rules, and LLM provider settings
- Choose model provider (`OpenAI`, `Azure OpenAI`, `OpenRouter`, `Custom`) with a URL and API key
- Preview the agent payload used by the backend
- Switch between single-agent and multi-agent workflows
- Local-only mock processing for demo purposes
